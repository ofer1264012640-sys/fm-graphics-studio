Guides

Learn how to create Football Manager graphics packs with FM Graphics Studio.

Getting Started

Open FM Graphics Studio and create a new project. Choose a name and select where you want to save it. Your project folder will contain all of your graphics files. You can then create folders, images and XML files. Use the Project Explorer to manage everything in one place.

Club Logos

Create a new image and choose Club Logo as the graphic type. Select the size you need, such as Small or Normal. Choose the source logo from your computer. FM Graphics Studio will resize it to the correct dimensions. The finished logo will be saved inside your project.

League Logos

Create a new image and select League / Competition Logo. Choose the required logo size for your graphics pack. Select the original competition logo from your computer. The program will resize and center the image automatically. You can then use the logo in your Football Manager pack.

Player Faces

Create a new image and select Player Face. Choose the appropriate face size for your graphics pack. Select a player photo from your computer. FM Graphics Studio will resize and center the image. The finished face can then be added to your Football Manager graphics.

Trophies

Create a new image and select Trophy. Trophy graphics use the dedicated trophy image size. Choose the trophy image you want to add to your project. The image will be resized and centered automatically. You can then use it as part of your Football Manager graphics pack.

XML Files

XML files tell Football Manager where your graphics should appear. Create an XML file inside the folder containing your graphics. FM Graphics Studio creates the basic configuration automatically. You can then add image mappings to the XML file. These mappings connect your graphics to the correct Football Manager IDs.
